# momo 아이디어 보강해보입시더 — 회의 자료

| 항목 | 내용 |
| --- | --- |
| 목적 | 외부 평가(“흔하다 / 수익 불확실 / 포트폴리오 약함”) |


---

## 0. 문제점

모모와 **똑같은 앱은 거의 없다.**  
다만 모모가 하려는 일을 **조각내서 더 잘하거나, 이미 습관이 된 앱은 많다.**

| 구분 | 내용 |
| --- | --- |
| 진짜 차별점 | 지도가 홈, 모임만의 합류 위치(끝나면 OFF), 오는 중 상태, 즉석 생활 모임(밥·스터디·택시) |
| 가짜 차별점 | 당도(=매너온도), 친구 위치(=카카오맵), 소개팅, AI 추천, “대학생 앱”(학교 인증 없음) |
| 평가가 나온 이유 | 같은 점 위에 다른 점을 올려 **만능 모임 앱**으로 읽힘 |
| 보강 방향 | 기능을 더 넣지 말고, **한 장면**을 고른다 |

이길 수 있는 문장:

> 사람은 에타에서 구하고, 위치는 카카오맵에서 보고, 모임은 당근에서 운영한다.  
> 모모는 그 세 개를 대체하는 앱이 아니라, **오늘 이 핀으로 모이는 동안만 쓰는 앱**이어야 한다.

---

## 1. 들어온 평가, 그대로

> 모모의 앱이 너무 흔해서 창의성이 돋보이지 않는다.  
> 우리만의 창의적인 아이덴티티를 생각할 필요가 있고, 앱의 수익성이 보장되지 않는다.  
> 좀 더 보강할 필요가 있다.

이 말은 기능이 모자라다는 뜻이 아니다.

- **창의성** = 한 줄로 기억되는 이유가 있는가
- **아이덴티티** = 복숭아 색깔이 아니라, **왜 이 앱만 켜는가**
- **수익** = 빈 지도·적은 유저에서도 돈이 도는 구조인가

지금 기획서는 두껍고, 제품 한 줄은 얇다.

---

## 2. 냉정한 내부 판단

### 맞는 말

- 창의적 아이덴티티가 약하다. 브랜딩(복숭아, 당도)은 있고 제품 문장은 없다.
- 수익 모델은 “나중에 광고”에 가깝다. 콜드 스타트와 광고는 같이 성립하기 어렵다.
- 기능을 보강하는 것보다, **무엇을 빼서 한 장면을 강하게 만들지**가 먼저다.

### 더 생각해보자

- 기획 명세 밀도는 학생 팀 기준에 비해 높다.
- **지금 데모 가능한 앱**으로 보강해라.
- “더 보강”을 기능 추가로 읽으면 더 흔해진다.

### 제일 위험한 대응

소개팅, AI, 광고, 태그 평가를 강화하거나 더 얹는 것.  
만능 앱에 가까워지고, 평가가 재확인된다.

---

## 3. 아이덴티티 회의때 더 생각해보자

세 안 모두 **기능을 더 넣는 안이 아니다.**  
앱이 “한 장면의 앱”이 되는 안이다.

공통으로 빼는 것:

- 소개팅을 1단 가치로 두지 않기
- AI를 정체성으로 내세우지 않기
- 당도를 차별점이라고 말하지 않기

---

### 1안. 게시판이 아니라 현장

**이런느낌:** 캠퍼스 반경 안에서, 앞으로 90분 안에 비는 사람만 지도에 뜬다.

**예를들어**  
시험 기간 저녁, 도서관 앞. 글 목록이 아니라 **지금 여기 있는 점**.  
“카공 1자리, 21:00까지” / “학식 지금” / “정문→역 22:40”.

**장치**

- 시간표 또는 “지금 가능” 토글이 소셜 그래프. 자산은 친구 수가 아니라 **겹치는 빈 시간**.
- 모임 수명 짧음. 90분이 지나면 지도에서 사라짐.
- 에타와의 차이: 그곳은 어제 글을 오늘 본다. 여기는 지금 안 오면 없다.

**죽일 것:** 정기 동아리, 온라인 게임, 소개팅, 며칠 뒤 모임.

**수익:** 빈 시간대 캠퍼스 카페·스터디카페 쿠폰. “지금 근처 자리”.

**데모:** 시간 슬라이더를 지금~90분으로 두자 점이 뜨고, 90초 만에 붙는다.

**약점:** 지금 하는 사람이 없으면 앱이 죽는다. **캠퍼스 하나**로 시작해야 한다.

**이 안이 깨는 평가:** 흔하다(에타 게시판과  comparables가 다름), 포트폴리오(한 장면이 보임).

---

### 2안. 목적지가 아니라 모이는 과정

**더 구상해보긴해야함:** 모임 정보는 어디서나 본다. 모모에서만 **모여드는 과정**을 본다.

**일단 이런느낌**  
풋살 4/10. 지도에 복숭아 네 개가 운동장으로 움직인다. 가까워질수록 익는다.  
채팅보다 **오는 몸**이 콘텐츠. 끝나면 위치 OFF.

**장치**

- 젠리 = 친구를 항상 본다. 모모 = **오늘 이 모임만, 모일 때만**.
- 당도를 개인 온도가 아니라 **이번 모임의 익은 정도**로 씀.
- 복숭아가 아이콘이 아니라 진행 상태.

**죽일 것:** 온라인 모임, 소개팅, 복잡한 카테고리 트리.

**수익:** 약함. 창의성·데모에는 가장 강함. 돈은 캠퍼스 이벤트·동아리 합류 지도 쪽이 맞다.

**데모:** 네 명이 한 핀에 모여드는 30초. 설명 없이 이해된다.

**약점:** “예쁜 젠리 모임판”으로 읽힐 수 있음. 평소 친구 추적 앱이 되면 안 된다.

**이 안이 깨는 평가:** 창의성. 수익은 잘 안 깨진다.

---

### 3안. 이건 다른앱에서 쓰던건데,, 안봐도 됌

**한 줄:** 같은 시간, 같은 방향으로 가는 사람만 붙인다. 일단 심야 귀가·역·캠퍼스 축.

**더 생각해보자**  
22:30 정문. “역까지 3/4, 2분 뒤 출발”. 화살표가 같은 방향을 본다.  
합류하면 위치 ON, 내리면 전부 OFF.

**장치**

- 매칭 축이 카테고리가 아니라 **출발–도착–시간 벡터**.
- 안전이 부가 기능이 아니라 제품. 당도 = 합승 신뢰.
- 에타 “택시 구함”과의 차이: 글이 아니라 **지금 이 화살표**.  
  카카오 T와의 차이: 기사가 아니라 **같이 가는 학생**.

**죽일 것:** 5종 카테고리, 취미, 소셜, 게임, 장기 모임. 밥약도 1안이 더 잘한다.

**수익:** 세 안 중 가장  spo 명확. 야간 편의점·버스 시간 제휴, 캠퍼스 안전.  
판매 단위 = “이 시간대 이 경로의 사람”.  
**규제:** 유상 운송이 되면 안 됨. **비용 더치의 학생 동행**으로 선 고정.

**데모:** 학교→역 화살표가 붙고, 도착 후 꺼진다.

**약점:** 사용 빈도가 밥약·카공보다 낮다. 역 축이 약한 학교면 죽는다.  
팀 서사(“모임 앱”)와는 거의 다른 앱이 된다.

**이 안이 깨는 평가:** 흔하다 + 수익 문장. 대신 제품 범위가 크게 줄어든다.

---

### 3안 고르는 기준

| 평가를 깨고 싶은 것 | 고를 안 |
| --- | --- |
| 창의성이 안 보인다 | **2안** |
| 실제로 쓰이게 하고 싶다 | **1안** |
| 수익·포지셔닝을 날카롭게 | **3안** |

**권고 (학생 팀, 지금 평가 기준):**  
**1안을 본류**로 두고, **2안의 복숭아 합류를 그 안의 감정**으로 넣는다.

- 정의: 모든 모임이 아니라 **지금 이 캠퍼스, 90분**
- 화면의 기억: **모여드는 복숭아**
- 소개팅·게임·정기 모임: 나중, 어쩌면 없음

3안은 택시만의 회사로 각오가 있을 때만.

---

## 4. 현존 서비스 조사 — 모모가 하려는 일 7개

1. 지금 근처 모임을 지도에서 본다  
2. 즉석 모임을 만든다 (밥·스터디·운동·택시·취미)  
3. 모르는 사람과 만난다  
4. 친구 위치를 본다 (젠리식)  
5. 모임 참여자끼리만 합류 위치를 본다  
6. 신뢰 점수(당도)로 사람을 거른다  
7. 대학생이 1차 타깃 (현재 기획은 학교 인증 없음)

경쟁은 이 축별로 갈린다. **한 앱이 7개를 다 하진 않는다.**

## 5. 관련 플랫폼 / 앱 목록

### 5.1 대학생이 이미 쓰는 곳

| 서비스 | 하는 일 | 모모와의 관계 |
| --- | --- | --- |
| **에브리타임** | 학교 게시판, 시간표, 중고책, 그룹챗. 2026 **지역채팅**(인접 대학 익명), **모임 일정 투표** | 번개·택시·미팅·게임 구인은 **이미 글/채팅으로** 됨. 지도·합류 위치 없음. MAU·학교 인증이 압도적 |
| **카카오톡 오픈채팅** | 즉시 방 입장, 링크 공유 | 모임 앱이 아니라 **습관**. 생성 마찰이 가장 낮음 |
| **네이버 밴드 / 카페** | 동아리·정기 모임 운영 | 즉석 번개가 아님 |
| **교내 합승 (예: CATXI)** | 같은 학교, 출발·도착 매칭 후 카카오T 호출 | 택시 한 축만 |

대학생의 “사람 구하기”는 에타+카톡에 있다.  
모모가 이길 지점은 **구하기가 아니라 모이는 과정**.

### 5.2 동네·취미 모임

| 서비스 | 하는 일 | 모모와의 관계 |
| --- | --- | --- |
| **당근 모임** | 동네 인증, 운동·동네친구. 출석 QR, 반복 일정, 일정별 채팅. 규모 큼 | **가까운 오프라인 모임**의 본진. 실시간 합류·90분 번개는 약함 |
| **소모임** | 취미 동호회, AI 매칭, 개설 유료 | 정기 취미. 대학 즉석 아님 |
| **문토** | 취향 소모임·원데이 | 큐레이션·결제형. 지도 탐색 아님 |
| **온모임** | 본인인증 강조 오프라인 | 안전은 더 강함. 캠퍼스 즉석은 약함 |
| **프립** | 강사 클래스 예약 | 참가자가 모임을 만드는 앱이 아님 |
| **Meetup** | 관심사 이벤트 | 국내 습관·밀도 약함 |
| **플랩 등** | 러닝 특화 | 한 카테고리만 깊게 |

겹침: 공개 모임, 카테고리, 참여, 채팅, 신고.  
안 함: **지도가 홈**, **지금 합류 위치**, **택시 벡터**.

### 5.3 위치 공유

| 서비스 | 하는 일 | 모모와의 관계 |
| --- | --- | --- |
| **젠리** | 친구 실시간 위치, 놀이 | **서비스 종료.** 감성 레퍼런스 |
| **Life360, 아이쉐어링** | 가족 안전, 도착 알림 | 친구 놀이가 아니라 보호 |
| **카카오맵 친구위치** | 톡 친구와 시간 제한 없이 위치, 그룹 | **이미 아는 사람**끼리 모일 때 충분 |
| **구글맵 / 애플 Find My** | 링크·가족 공유 | 모임 발견과 무관 |
| **Bump (해외)** | 젠리 계승 + 캠퍼스 디렉터리 | 친구 위치 소셜. 공개 번개 생성은 약함 |

젠리식 친구 위치는 카카오맵이 한다.  
모모만의 위치 = **이 모임 참여자에게만, 끝날 때 꺼진다.**

### 5.4 합승·이동

| 서비스 | 하는 일 | 모모와의 관계 |
| --- | --- | --- |
| **카카오 T / 우티** | 기사 호출 | 학생끼리 더치가 아님 |
| **반반택시** | 경로 유사 승객 합승, 동성, 실명·결제 | **합법인 합승 중개** |
| **에타 택시 구함 글** | 게시판 | 실시간 지도·합류 없음 |

모모 택시 = 기사가 아니라 **동행자를 찾는 게시판의 지도판**.  
차별점이자 규제·안전 리스크.

### 5.5 스터디·밥약·소개팅·캠퍼스 소셜 (조각)

| 서비스 | 하는 일 |
| --- | --- |
| **열품타** | 공부 시간·캠스터디. 오프라인 집결 아님 |
| **위피, 글램, 틴더, 아만다** | 소개팅. 지도 번개 아님 |
| **Bumble BFF** | 친구 만들기 스와이프 |
| **Butterfly, Pingg, Proxima (해외 캠퍼스)** | 학교 인증 + 지금 캠퍼스에서 누가 있는지 |

밥약·스터디·소개팅을 한 앱에 넣은 것은 모모의 **넓음**이지, 각 축의 승리가 아니다.

### 5.6 신뢰

| 서비스 | 하는 일 |
| --- | --- |
| **당근 매너온도** | 거래 후 평가 → 온도 |
| **소모임 평점·후기** | 모임 후기 |
| **온모임 본인인증** | 입장 전 인증 |

모모 당도 = 매너온도의 모임판. 이름만 다르고 메커니즘은 같다.

## 7. 진짜 다른 점 / 안 다른 점

### 7.1 기존 앱을 다 겹쳐도 한 제품 안에 없는 것

1. **지도가 게시판이 아니라 홈**
2. **모임 스코프 위치 + 끝나면 강제 OFF**  
   (카카오맵 = 친구와 오래, 젠리 = 친구를 항상)
3. **합류 현황이 기능**  
   당근 = 도착 후 QR. 모모 = **오는 중**.
4. **즉석 × 공개 × 캠퍼스 생활(밥·스터디·택시)을 한 지도에**

이 4개가 기획상 차별점이다.  
복숭아·당도·AI는 차별점이 아니다.

### 7.2 달라 보이지만 안 다른 점

- 당도 ≈ 당근 매너온도 + 태그 후기
- 친구 위치 ≈ 카카오맵 친구위치
- 모임 CRUD·채팅·신고 ≈ 당근 / 소모임 / 문토
- 소개팅 ≈ 위피·에타 미팅방보다 약하고 위험만 큼
- AI 추천·초안 ≈ 흔한 보조 기능
- “대학생 앱” ≈ 에타가 학교 인증·시간표·MAU를 가짐. 모모는 아무 메일 가입이라 **대학생 전용이 아님**

기능 목록을 펼치면: **새로운 동사 하나 + 이미 있는 동사 여러 개.**  
새로운 동사 = “지도에서 보고, 모여드는 걸 본다.”

## 8. 빈자리 vs 이미 메워진 자리

### 아직 약한 빈자리 (들어갈 틈)

- 에타 글 → 카톡 방 → 카카오맵 위치의 **3앱 점프**
- “오늘, 캠퍼스 근처, 1~2시간짜리” 즉석
- 모르는 사람과 모이되 **오는 길이 보이게**
- 심야 역·정문 축의 학생 동행 (반반택시와 다른 레이어)

### 이미 메워져서 이기기 어려운 자리

| 자리 | 승자 |
| --- | --- |
| 학교 커뮤니티, 강의·시간표 | 에브리타임 |
| 지금 바로 말 걸기 | 카카오톡 |
| 동네 정기 취미 | 당근 모임 |
| 가족/연인 위치 | 카카오맵, Life360 |
| 소개팅 | 데이팅 앱 |
| 합법 택시 합승 중개 | 반반택시 |
| 공부 인증 | 열품타 |

이 강한 자리를 **같이** 먹으려 하면 흔해 보인다.  
빈자리만 붙이면 “에타+카톡+맵을 한 번에”가 된다.

## 9. 수익 — 평가가 가리키는 것

“수익이 보장되지 않는다”는, 사업계획서가 없어서가 아니라 **이 카테고리의 기본 경제학이 불리하다**는 뜻에 가깝다.

- 지도가 비면 유저가 없고, 유저가 없으면 광고가 없다.
- Maps API·서버·OTP·AI 비용이 광고보다 먼저 나간다.
- 스폰서드·제휴는 **아직 유저 없는 앱에 누가 돈을 내느냐**의 세일즈 문제다.
- 1회 부스트는 모임이 **많이 생긴 뒤**의 상품이다.

아이덴티티 안과 수익의 궁합:

| 안 | 수익 설득력 |
| --- | --- |
| 1안 지금 90분 | 빈 시간대 로컬 쿠폰. 콜드스타트와 맞춤 |
| 2안 익어가는 모임 | 약함. 감성·데모용 |
| 3안 같은 방향 | 경로·시간대 단위 제휴. 규제 선 필요 |

## 10. 회의에서 결정할 것

기획서 수정 전에, 아래만 고르면 된다.

1. **우리가 대체할 앱은 뭔가?**  
   (에타 / 당근 / 카카오맵 / 아무 것도 대체하지 않고 “모이는 동안만”)
2. **아이덴티티 1·2·3안 중 본류는?**  
   권고: 1안 + 2안의 합류 연출
3. **영원히 안 할 것 3개**  
   예: 소개팅, 온라인 게임, 정기 동아리
4. **첫 캠퍼스 하나**  
   90분 안은 전국 앱으로 시작하면 성립하지 않는다
5. **다음 스프린트 데모 한 장면**  
   인증 화면이 아니라, 지도에서 점이 붙거나 복숭아가 모이는 화면

## 11. 한 줄

모모의 차별점은 새로운 카테고리가 아니라, **이미 흩어진 습관을 한 지도에 묶는 것**이다.

- 남과 다른 점: 지도 홈, 모임만의 합류 위치, 도착 전 상태, 즉석 생활 모임
- 남과 같은 점: 모임 CRUD, 채팅, 신고, 신뢰점수, 친구 위치, 소개팅, AI
- 보강 = 같은 점을 줄이고, 다른 점 하나를 제품의 전부로 만드는 것
